# QR Code Generator (Streamlit)
A simple, fast, and user-friendly QR Code Generator built with **Python**, **Streamlit**, and the **qrcode** library.  
Users can generate QR codes instantly from any text or URL and download them as PNG images—all through a clean web interface.
---
## 🚀 Features
- Generate QR Codes from any text or URL  
- Live QR Code preview  
- Download QR Code as a PNG image  
- Fully web-based (runs on Streamlit)  
- Lightweight and fast  
- Open-source and easy to customize  
---
## 🛠️ Technologies Used
- Python 3  
- Streamlit  
- qrcode  
- Pillow (PIL)  
---
